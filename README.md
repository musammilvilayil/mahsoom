# Mahsoom's Lifestyle Centre

Conversion-first website for Mahsoom's Lifestyle Centre, focused on:

- before/after transformation storytelling
- healthy-weight and nutrition guidance
- active lifestyle support
- Vritilife skin self-care education
- consultation lead capture
- mobile-first conversion

## Run locally

```bash
npm install
npm run dev
```

## Before launch

1. Replace demo transformation frames with real, consented member photos and verified outcome copy.
2. Add the club WhatsApp number to `WHATSAPP_NUMBER` in `app/page.tsx` using country code and digits only.
3. Add exact location, timings, Instagram and Google Business details when available.
4. Keep health/product statements aligned with current Herbalife India labels and official guidance.
5. Do not publish guaranteed weight-loss, disease-treatment or fabricated testimonial claims.

## Brand

Primary palette is derived from the supplied Mahsoom's Lifestyle Centre logo: deep green, black, warm ivory and a lime wellness accent.
